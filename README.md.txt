# Description

This project demonstrates the use of methods in Java. It includes methods that perform mathematical calculations, process arrays, check numbers, and manipulate strings.

# Activities Included

 Beginner Tasks

1. `greetUser()` – Displays a welcome message.
2. `add()`, `subtract()`, `multiply()`, and `divide()` – Perform basic arithmetic operations.
3. `factorial()` – Calculates the factorial of a number.
4. `sumArray()` – Calculates the sum of array elements.
5. `isPrime()` – Checks whether a number is prime.

 Additional Tasks

6. `maxInArray()` – Finds the largest number in an array.
7. `gcd()` and `lcm()` – Calculate the Greatest Common Divisor and Least Common Multiple.

 Challenge Tasks

8. `recursiveFactorial()` – Calculates factorial using recursion.
9. `fib()` – Generates a Fibonacci number using recursion.
10. `isPalindrome()` – Checks whether a word is a palindrome, ignoring letter case.
